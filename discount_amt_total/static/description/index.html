Total Discount Amount

This module enhances Odoo 18 accounting, Sales, Purchase documents by clearly displaying the Total Discount Amount directly in the Totals section.

By default, Odoo applies discounts silently at the line level. This customization improves transparency by explicitly showing how much discount has been applied on Sales, Purchase, invoices, bills, and credit notes.

How It Works (Simple Explanation)

  • The system reads all line items.
  • Total amount before discount is calculated.
  • Total amount after discount is calculated.
  • The difference is computed as Total Discount Amount.
  • The discount value is added to Odoo’s tax totals data.
  • The value is displayed automatically in the UI.

Usage – How to Use It

  1. Install the Total Discount Amount module.
  2. Open any Sale, Purchase, Customer Invoice, Vendor Bill, or Credit Note.
  3. Add products with line-level discounts.
  4. Scroll to the Tax Totals section.
  5. View the automatically calculated Discount Amount.
  6. If document currency differs, company currency discount is also shown.

Key Benefits

  • Clear visibility of total discount
  • Improves Amount transparency
  • Multi-currency discount support
  • No impact on accounting entries
  • Works with all tax configurations
  • Upgrade-safe implementation

Complete Flow Steps (Behind the Scenes)

  1. User opens an accounting document.
  2. Odoo prepares tax totals using invoice base lines.
  3. Total before discount is calculated.
  4. Total after discount is calculated.
  5. Discount amount is derived.
  6. Currency conversion is applied if needed.
  7. QWeb template renders the discount in the UI.

🔐 Security & Control

  • No New fields
  • No sensitive data stored
  • No external API calls
  • No database structure changes
  • Uses standard Odoo inheritance
  • Safe for production environments
